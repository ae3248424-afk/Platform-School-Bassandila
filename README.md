# منصة المدرسة | School Platform

نظام إدارة مدرسة متكامل واحترافي، قابل للتطوير والصيانة. مبني باستخدام React وTypeScript وVite وTailwind CSS وSupabase.

## الميزات

- **أربع لوحات مستقلة**: الطالب، المدرس، الإدارة، ولي الأمر
- **واجهة عربية RTL** مع خط Cairo وتصميم متجاوب
- **مصادقة آمنة** عبر Supabase Auth (كلمات المرور مشفرة، لا تُخزن كنص صريح)
- **صلاحيات على مستوى قاعدة البيانات** عبر Row Level Security (RLS)
- **21 فصلًا** (12 للصف الأول الثانوي، 9 للثاني) سعة كل منها 60 طالبًا (إجمالي 1,260)
- **استيراد جماعي** للطلاب والمدرسين من CSV
- **نشر المحتوى** للمدرسين (أخبار/امتحانات/ملفات/تذكيرات) موجه للفصول المسندة فقط
- **تطبيق الصلاحيات** على مستوى قاعدة البيانات وليس الواجهة فقط

### لوحة الطالب
- عرض الدرجات والمواد والجداول الدراسية
- عرض الواجبات ومواعيد التسليم
- عرض الحضور والغياب
- عرض منشورات المدرسين (أخبار/امتحانات/ملفات) الخاصة بفصله ومواده
- عرض إعلانات المدرسة

### لوحة المدرس
- عرض الفصول والمواد المعيّن عليها
- تسجيل الدرجات وتعديلها
- إنشاء الواجبات
- تسجيل الحضور والغياب للفصول المسندة فقط
- نشر منشورات (أخبار/امتحانات/ملفات/تذكيرات) للمواد المسندة فقط
- تحديد الفصول المستهدفة من بين الفصول المسندة فقط
- لا يمكن للمدرس تعديل أو حذف محتوى مدرس آخر (مطبق عبر RLS)

### لوحة الإدارة
- **إدارة الطلاب**: إضافة فردية أو استيراد CSV، بحث بالاسم/رقم الطالب/اسم المستخدم
- **إدارة المدرسين**: إضافة فردية أو استيراد CSV، بحث بالاسم/الرقم الوظيفي/اسم المستخدم
- **إنشاء حسابات آمن**: كلمات مرور عشوائية، إنشاء عبر edge function بمفتاح الخدمة
- **إعادة تعيين كلمة المرور** لأي مستخدم
- **تفعيل/إيقاف الحسابات**
- عرض السعة المسجلة والمتبقية لكل فصل
- عدادات: إجمالي الطلاب، المدرسين، الفصول، الحسابات النشطة
- إدارة المواد والفصول والجداول والإعلانات
- ربط أولياء الأمور بأبنائهم
- عرض التقارير والإحصائيات

### لوحة ولي الأمر
- متابعة الأبناء المرتبطين بحسابه فقط
- عرض درجات كل ابن وحضوره وواجباته
- عرض منشورات المدرسين لفصول أبنائه
- عرض إعلانات المدرسة

## الأمان

- مصادقة آمنة عبر Supabase Auth
- صلاحيات حسب الدور (admin, teacher, student, parent)
- سياسات Row Level Security على جميع الجداول
- منع الطالب من الاطلاع على بيانات الطلاب الآخرين
- منع ولي الأمر من الاطلاع إلا على بيانات أبنائه
- تقييد المدرس بالفصول والمواد المعيّن عليها (دالة `can_teacher_post_to`)
- منع تجاوز سعة الفصل (trigger `enforce_class_capacity`)
- إنشاء حسابات الإدارة عبر edge function بمفتاح الخدمة (service role)
- كلمات المرور لا تُخزن كنص صريح ولا تُولّد كقيم موحدة
- حساب المدير الأول: يظهر خيار "مدير النظام" في صفحة التسجيل فقط عندما لا يوجد أي مدير في النظام

## قاعدة البيانات

الجداول الرئيسية:

| الجدول | الوصف |
|--------|-------|
| `profiles` | ملفات المستخدمين (دور، اسم، حالة، اسم مستخدم) |
| `classes` | الفصول الدراسية (سعة 60 لكل فصل) |
| `subjects` | المواد الدراسية (12 مادة) |
| `class_subjects` | ربط المدرس بالمادة والفصل |
| `students` | بيانات الطلاب (رقم طالب فريد) |
| `teachers` | بيانات المدرسين (رقم وظيفي فريد) |
| `parents` | بيانات أولياء الأمور |
| `parent_student_links` | ربط أولياء الأمور بالطلاب |
| `enrollments` | تسجيل الطلاب في الفصول |
| `grades` | درجات الطلاب |
| `assignments` | الواجبات |
| `attendance` | سجل الحضور والغياب |
| `announcements` | إعلانات المدرسة |
| `schedules` | الجداول الدراسية |
| `teacher_posts` | منشورات المدرسين (أخبار/امتحانات/ملفات/تذكيرات) |

### دوال وسياسات قاعدة البيانات

| الدالة/السياسة | الوصف |
|----------------|-------|
| `is_admin()` | التحقق من أن المستخدم الحالي مدير |
| `is_teacher_of_class(class_id)` | التحقق من أن المدرس معيّن على الفصل |
| `is_parent_of(student_id)` | التحقق من أن ولي الأمر مربوط بالطالب |
| `get_current_user_role()` | الحصول على دور المستخدم الحالي |
| `can_teacher_post_to(teacher_id, class_id, subject_id)` | التحقق من أن المدرس يمكنه النشر للفصل والمادة |
| `get_class_enrollment_count(class_id)` | عدد الطلاب المسجلين في فصل |
| `enforce_class_capacity` | trigger يمنع تجاوز سعة الفصل (60) |

## دليل إضافة الطلاب والمدرسين الحقيقيين

### الخطوة 1: إنشاء حساب المدير الأول
1. افتح صفحة التسجيل (حساب جديد)
2. إذا لم يوجد مدير في النظام، سيظهر خيار "مدير النظام"
3. أنشئ الحساب بإدخال الاسم والبريد وكلمة المرور

### الخطوة 2: إضافة الطلاب
**إضافة فردية:**
1. سجّل دخولك كمدير
2. اذهب إلى تبويب "الطلاب"
3. اضغط "إضافة طالب"
4. أدخل: الاسم الكامل، البريد الإلكتروني، رقم الطالب، الفصل
5. النظام ينشئ حساب دخول تلقائيًا بكلمة مرور عشوائية
6. كلمة المرور تظهر مرة واحدة في نافذة النجاح — انسخها وسلّمها للطالب

**استيراد CSV:**
1. اذهب إلى تبويب "الطلاب" → "استيراد CSV"
2. الملف يجب أن يحتوي الأعمدة: `full_name`, `email`, `student_number`, `class_name`
3. `class_name` يجب أن يطابق اسم فصل موجود (مثل "الصف العاشر - 1")
4. النظام يتحقق من عدم تكرار الأرقام وأسماء المستخدمين
5. تظهر الأخطاء لكل صف على حدة

### الخطوة 3: إضافة المدرسين
**إضافة فردية:**
1. اذهب إلى تبويب "المدرسون"
2. اضغط "إضافة مدرس"
3. أدخل: الاسم الكامل، البريد، الرقم الوظيفي، التخصص
4. كلمة المرور العشوائية تظهر مرة واحدة

**استيراد CSV:**
1. الأعمدة: `full_name`, `email`, `employee_number`, `specialization`
2. النظام يتحقق من عدم تكرار الأرقام الوظيفية

### الخطوة 4: تعيين المدرسين على الفصول والمواد
1. اذهب إلى تبويب "الصفوف والفصول"
2. اضغط "تعيين مدرس" على الفصل المطلوب
3. اختر المدرس والمادة
4. بعد التعيين، يمكن للمدرس نشر المحتوى وتسجيل الدرجات والحضور لهذا الفصل

### الخطوة 5: تسليم بيانات الدخول بأمان
- **كلمات المرور تُولّد عشوائيًا** وتظهر مرة واحدة فقط عند إنشاء الحساب
- **لا تُخزّن كنص صريح** في أي مكان في قاعدة البيانات
- **طريقة التسليم الآمنة:**
  - اطبع بيانات الدخول (اسم المستخدم + كلمة المرور) في ورقة مغلقة
  - سلّمها للطالب/المدرس يدويًا في المدرسة
  - أو استخدم قناة خاصة ومشفرة (رسالة نصية مباشرة)
  - لا ترسلها عبر بريد إلكتروني غير مشفر أو مجموعات عامة
- **إعادة تعيين كلمة المرور:**
  - المدير يذهب إلى تبويب "المستخدمون"
  - يضغط أيقونة المفتاح بجانب المستخدم
  - النظام يولّد كلمة مرور عشوائية جديدة
  - كلمة المرور الجديدة تظهر مرة واحدة — سلّمها للمستخدم
